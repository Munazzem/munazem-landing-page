# صفحة الهبوط وتطبيق منظم لولي الأمر (PWA & Android APK)

مشروع مستقل وخفيف بالكامل ومصمم ليتحمل ملايين الزيارات دون أي استهلاك لموارد السيرفر، وجاهز للرفع الفوري على **Vercel** أو أي استضافة ثابتة.

---

## 📁 محتويات المجلد

- `index.html`: صفحة الهبوط الرئيسية بهوية "منظم" واللون الكحلي الداكن الفخم.
- `style.css`: تنسيقات وتصميم عصري (Glassmorphism، خط Cairo، متجاوب بالكامل مع الجوال).
- `script.js`: منطق التفاعل، التعرف التلقائي على جهاز الزائر (iOS أو Android)، وأكورديون الأسئلة الشائعة.
- `config.js`: ملف الإعدادات المركزي لتغيير الروابط والبيانات بسهولة.
- `assets/`: الشعار والأيقونات الرسمية.
- `app/`: تطبيق ولي الأمر الكامل كـ **PWA** للآيفون مع دعم وضع الشاشة الكاملة (Standalone).
- `vercel.json`: إعدادات الاستضافة والتوجيه السلس على Vercel.

---

## 🚀 كيفية الرفع على Vercel في دقائق

### الطريقة الأولى: عبر لوحة تحكم Vercel (الأسهل)
1. ارفع مجلد `landing` في مستودع مستقل على GitHub (مثلاً: `monazem-landing`).
2. افتح حسابك على [Vercel](https://vercel.com) واضغط على **Add New Project**.
3. اختر المستودع `monazem-landing` ثم اضغط **Deploy**.
4. ستحصل فوراً على رابط مجاني فائق السرعة مثل: `https://monazem-app.vercel.app`.
5. يمكنك ربط دومين مخصص مثل: `app.munazzem.tech` أو `parent.munazzem.tech`.

### الطريقة الثانية: عبر سطر الأوامر (Vercel CLI)
داخل مجلد `landing`:
```bash
npx vercel
```
ثم للإنتاج:
```bash
npx vercel --prod
```

## 📦 أين ترفع ملف تطبيق الأندرويد APK (الـ 104 ميجابايت)؟

نظراً لأن حجم ملف الـ APK هو **104 ميجابايت** (وهو يتجاوز حد الـ 100 ميجا لرفع الملفات العادية على مستودعات Git المجانية)، أفضل الطرق وأكثرها سرعة واحترافية:

### الخيار 1: GitHub Releases (مجاني وسريع جداً CDN - يُنصح به ⭐)
1. في مستودع مشروعك على GitHub، اذهب إلى تبويب **Releases** ثم اضغط **Create a new release**.
2. اكتب رقم الإصدار `v1.0.0`.
3. اسحب ملف `monazem-parent.apk` وأفلته في المربع (يدعم حتى 2 جيجابايت للملف الواحد مجاناً).
4. اضغط **Publish release**.
5. انسخ رابط التحميل المباشر للملف، ثم افتح ملف `config.js` وضعه في متغير `apkDownloadUrl`:
   ```javascript
   apkDownloadUrl: "https://github.com/USERNAME/REPO/releases/download/v1.0.0/monazem-parent.apk",
   ```

### الخيار 2: Google Drive
1. ارفع ملف الـ APK على حساب Google Drive.
2. اجعل الرابط متاحاً للعامة (Anyone with the link can view).
3. حوّل الرابط إلى رابط تنزيل مباشر وضعه في `config.js`.

### الخيار 3: رابط بناء Expo EAS المباشر
إذا قمت ببناء التطبيق عبر `eas build -p android --profile production`، يعطيك Expo رابط تنزيل مباشر لملف الـ APK، يمكنك نسخه ولصقه مباشرة في `config.js`.

## 📱 كيف يعمل تطبيق الآيفون (PWA)؟

1. عند دخول ولي الأمر من الآيفون والضغط على "تشغيل تطبيق الويب"، يفتح الرابط `/app/` في متصفح Safari.
2. يضغط ولي الأمر على زر المشاركة (Share ⎋) ثم يختار **"إضافة إلى الشاشة الرئيسية" (Add to Home Screen ➕)**.
3. يثبت التطبيق فوراً على شاشة هاتفه باسم "منظم" وأيقونة التطبيق الرسمية.
4. عند فتحه، يعمل بوضع الشاشة الكاملة (Standalone) كأنه تطبيق محمل من الآب ستور تماماً بدون أي أشرطة متصفح وبكامل مميزات الحساب وكارت الطالب وتسجيل الدخول.
